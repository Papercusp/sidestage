The seven corrections travel together

Any production direction should adopt all seven. Choosing a layout does not soften the factual verdict.

Clients

Responsive web ships; native download links are placeholders.

Redis

Provisioned, but no current application consumer.

Copilot

Question + lineup + catalog + transcript moments + policy; not room history.

Auction state

Current UI reads shared sync; direct ordered SSE remains available.

Guarded actions

Audited and rollback-capable, not universally audit-first or fully reversible.

Acceptance

Ledger/substrate ship; deployed worker currently executes Actions only.

Authority rule

Scope “server-authoritative” to event commerce, ownership, policy, payment settlement, and guarded automation. Keep the legacy product-only cart visible as a compatibility path.
